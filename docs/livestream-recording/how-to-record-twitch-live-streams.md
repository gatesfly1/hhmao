# 如何录制 Twitch 的直播？

**Twitch** 是全球最大的游戏直播平台，汇聚了海量主播的精彩直播内容。如果你想录制喜欢的直播节目以便后续回看，使用**哼哼猫**软件可以轻松实现实时录制。只需两步操作，即可将正在进行的直播保存到本地。

## 第一步：复制直播间链接

打开 Twitch 网站，进入你想录制的直播间。在浏览器地址栏中复制完整的直播间链接（格式通常为 `https://www.twitch.tv/主播用户名`）。

## 第二步：粘贴链接并开始录制

打开**哼哼猫**软件，选择左侧菜单的「**链接下载**」功能。将刚才复制的 Twitch 链接粘贴到输入框中，点击绿色的「**提取**」按钮。

软件会自动解析直播内容，并在下方列表中显示可下载的媒体文件（包括视频流、音频和封面图）。第一行会显示「**直播**」状态标签，表示正在实时录制。你可以看到实时下载速度和已录制的文件大小。

:::tip
直播录制会持续进行，直到主播结束直播或你手动停止。录制的视频文件会自动保存到软件设置的下载目录中。
:::
