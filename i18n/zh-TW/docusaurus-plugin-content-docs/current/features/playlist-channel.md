# 播放列表 / 頻道下載

支持 YouTube、Instagram、Twitter、TikTok、Bilibili 等平臺作者主頁、頻道、播放列表和 Hashtag 列表批量解析下載，自動獲取全部作品。

## 主頁批量提取

輸入作者主頁 URL，選擇翻頁數量或全量，系統會按發佈順序取回該作者公開的全部內容。

## 播放列表

YouTube Playlist、Bilibili 收藏夾等結構化列表會被識別為播放列表，下載時按原順序保留。

## Hashtag

TikTok、Instagram、Twitter 上的 #標籤 頁面也能批量解析。注意平臺對 hashtag 內容的展示本身有限，熱門頁 ≠ 全部。
