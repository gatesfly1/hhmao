# 如何錄製 Kick 直播？

本文介紹如何使用哼哼貓電腦軟件錄製 Kick 平臺的直播內容，以及下載 Kick 平臺已有的視頻。

## 功能說明

哼哼貓電腦軟件支持兩種 Kick 內容獲取方式：

1. **直播錄製** —— 實時錄製 Kick 平臺的直播流
2. **視頻下載** —— 下載 Kick 平臺的已發佈視頻內容

兩種功能都通過「**鏈接下載**」功能實現，操作流程完全相同。

## 第一步：複製 Kick 鏈接

### 錄製直播

進入想要錄製的 Kick 直播間，**複製瀏覽器地址欄中的鏈接**：

`https://kick.com/[主播用戶名]`

例如：`https://kick.com/jupi`

:::tip
- 點擊「複製鏈接」按鈕快速複製直播間鏈接
- 或從網址欄直接複製整個鏈接
:::

### 下載已發佈視頻

進入 Kick 平臺的視頻鏈接，**複製視頻頁面的鏈接**：

`https://kick.com/[主播用戶名]/videos/[視頻ID]`

例如：`https://kick.com/jeff-jian-57/videos/4ef3e6bc-d963-4a04-8b3a-dd0cc0c66f89`

操作方式與直播錄製相同。

## 第二步：粘貼鏈接並開始

打開哼哼貓軟件，進入「**鏈接下載**」功能：

1. **粘貼鏈接** —— 將複製的 Kick 鏈接粘貼到文本框中
2. **提取直播間信息** —— 點擊「**提取**」按鈕，軟件會自動解析該鏈接
3. **開始錄製 / 下載** —— 點擊「**開始錄製**」按鈕，開始實時錄製或下載視頻

**軟件會自動顯示**：

- 直播流信息（用於錄製）或視頻信息（用於下載）
- 提取結果包括視頻流、音頻流和封面圖
- 下載進度實時顯示

## 使用提示

| 項目 | 說明 |
|---|---|
| **直播錄製** | 實時錄製正在進行的直播，可隨時點擊停止 |
| **視頻下載** | 下載已發佈的視頻，通常速度更快 |
| **保存位置** | 所有文件默認保存到軟件設置的下載文件夾 |
| **文件格式** | 自動下載最高質量的視頻和音頻 |
| **網絡要求** | 需要穩定的網絡連接，建議使用有線網絡 |

## 常見問題

**Q：可以同時錄製多個直播嗎？**

A：哼哼貓支持批量處理，可以添加多個鏈接到隊列中順序處理。

**Q：直播錄製時間有限制嗎？**

A：沒有時間限制，可以一直錄製直到直播結束或手動停止。

**Q：下載的文件在哪裡？**

A：所有下載文件保存在哼哼貓的下載文件夾中，可在軟件設置中查看或修改保存位置。
