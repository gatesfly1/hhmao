# YouTube subtitle download — multi-language, multi-format

Subtitles are huge for language learning, comprehension and remix work. Meowload offers **two convenient ways** to download YouTube subtitles — multiple languages and formats, for any scenario.

## Option 1: Desktop app (recommended for SRT)

### Steps

1. **Copy the video link** — find the YouTube video and copy its share link (e.g. `https://youtu.be/Ah_uuTwGOYU`)
2. **Open Meowload** — launch the desktop app and pick **Link download** in the left menu
3. **Paste and extract** — paste the YouTube link and click the green **Extract** button
4. **Pick a language and download** — if the video has subtitles, the results table will show them. Click the language drop-down on the right and pick what you need (e.g. Simplified Chinese, English), then hit Download

### Highlights

- **Simple workflow** — same as downloading video, audio, images; you can grab everything at once
- **SRT by default** — the most universally compatible subtitle format
- **Format limit** — SRT only; for other formats use Option 2

## Option 2: Web tool (multiple formats)

### Steps

1. **Open the web tool** — go to the Meowload [**YouTube subtitle downloader**](https://hhmao.cn/youtube-subtitle-downloader)
2. **Paste and extract** — paste the YouTube link into the box and click **Single link extract**
3. **Pick language and format** — once parsed, the page lists every available language. For each language, the **format drop-down** next to the label lets you choose the subtitle format
4. **Download** — pick a language and format, then click Download to save

### Supported subtitle formats

| Format | Description | Best for |
|---|---|---|
| **SRT** | The most universal subtitle format | Video editors, players, subtitle-translation tools |
| **VTT** | Web video subtitle standard | Web players, HTML5 video |
| **TTML** | Timed Text Markup Language | Pro video production, broadcast |
| **JSON3** | JSON-formatted subtitle data | Developers, data analysis, programmatic processing |
| **SRV1 / SRV2 / SRV3** | YouTube's native subtitle formats | Special use cases, format research |

### Highlights

- **Rich formats** — SRT / VTT / TTML / JSON3 / SRV1 / SRV2 / SRV3 and more
- **No install** — works on any device through the web

## FAQ

**Q: What if the video has no subtitles?**

A: Some videos have no uploaded subtitles, in which case no subtitle option shows in the results. Try checking if the video has auto-generated subtitles.

**Q: Are the subtitles bilingual?**

A: Subtitles are single-language. For bilingual, download both languages and merge them with a subtitle editor.

**Q: How do I use the subtitle file?**

A: SRT subtitles load in players like VLC or PotPlayer, or import into editors like PR or Jianying (CapCut).
