# 如何錄製 Twitch 的直播？

**Twitch** 是全球最大的遊戲直播平臺，匯聚了海量主播的精彩直播內容。如果你想錄制喜歡的直播節目以便後續回看，使用**哼哼貓**軟件可以輕鬆實現實時錄製。只需兩步操作，即可將正在進行的直播保存到本地。

## 第一步：複製直播間鏈接

打開 Twitch 網站，進入你想錄制的直播間。在瀏覽器地址欄中複製完整的直播間鏈接（格式通常為 `https://www.twitch.tv/主播用戶名`）。

## 第二步：粘貼鏈接並開始錄製

打開**哼哼貓**軟件，選擇左側菜單的「**鏈接下載**」功能。將剛才複製的 Twitch 鏈接粘貼到輸入框中，點擊綠色的「**提取**」按鈕。

軟件會自動解析直播內容，並在下方列表中顯示可下載的媒體文件（包括視頻流、音頻和封面圖）。第一行會顯示「**直播**」狀態標籤，表示正在實時錄製。你可以看到實時下載速度和已錄製的文件大小。

:::tip
直播錄製會持續進行，直到主播結束直播或你手動停止。錄製的視頻文件會自動保存到軟件設置的下載目錄中。
:::
