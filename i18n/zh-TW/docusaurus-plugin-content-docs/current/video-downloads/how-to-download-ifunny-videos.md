# 如何下載 iFunny 視頻？

**iFunny** 是一個國外熱門的搞笑內容社區，彙集了大量有趣的 meme 圖片、GIF 和短視頻。如果你在 iFunny 上看到喜歡的視頻想保存到本地，只需兩步即可輕鬆下載。

## 第一步：複製視頻鏈接

打開 iFunny 網站，找到你想下載的視頻。在視頻播放區域的下方，點擊 **Copy link** 按鈕，頁面頂部會提示「link copied」，說明鏈接已成功複製到剪貼板。

## 第二步：粘貼鏈接並下載

打開**哼哼貓**，選擇左側菜單的「**鏈接下載**」功能。將剛才複製的鏈接粘貼到輸入框中，點擊綠色的「**提取**」按鈕。

軟件會自動解析鏈接內容，並在下方列表中顯示可下載的媒體文件（包括視頻和封面圖片）。你可以選擇「僅下載視頻」或「全部下載」，文件會自動保存到本地。
