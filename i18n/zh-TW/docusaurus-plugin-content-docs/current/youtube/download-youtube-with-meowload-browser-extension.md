# 使用哼哼貓瀏覽器插件下載 YouTube 視頻

## 問題背景

使用客戶端下載 YouTube 視頻時，部分用戶反饋遇到 **403 錯誤**。這通常是由於網絡限制或 YouTube 的防爬蟲機制導致的。

使用哼哼貓瀏覽器插件可以有效繞過這些限制，提供更穩定的下載體驗。此外，瀏覽器插件方式還支持下載 **年齡限制視頻** 和 **地區限制視頻**。

## 瀏覽器插件下載 YouTube 操作步驟

### 1️⃣ 安裝瀏覽器插件

如果瀏覽器尚未安裝哼哼貓插件，請先參考 [安裝教程](../browser-extension/install-meowload-extension.md) 完成安裝。

### 2️⃣ 訪問 YouTube 視頻

在瀏覽器中正常訪問要下載的 YouTube 視頻頁面。

### 3️⃣ 點擊下載按鈕

視頻頁面加載完成後，您會看到哼哼貓插件的 **下載按鈕**。**點擊下載按鈕** → 選擇視頻質量和格式 → 確認下載。

### 4️⃣ 等待下載完成

插件會自動將視頻保存到您在瀏覽器插件內配置的下載文件夾。

## 常見問題

### ❓ 下載後的視頻無法播放

**原因**：可能是瀏覽器或系統缺少相應的視頻解碼器。

**解決方案**：

- 確保選擇了 MP4 格式（最兼容）
- 在系統中安裝完整的視頻解碼器
- 嘗試使用其他視頻播放器打開

### ❓ 找不到下載按鈕

**原因**：插件可能未正確加載或需要刷新。

**解決方案**：

- 刷新頁面（F5 或 Ctrl+R）
- 檢查插件是否已啟用（瀏覽器擴展管理中）
- 嘗試重啟瀏覽器
- 更新插件到最新版本
