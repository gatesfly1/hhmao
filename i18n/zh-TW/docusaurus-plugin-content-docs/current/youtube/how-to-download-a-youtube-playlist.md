# 如何下載 YouTube 播放列表

YouTube 上有數百萬個播放列表，涵蓋音樂專輯、教學系列、精選合集等各類主題。將整個播放列表保存到本地，方便離線觀看、學習或個人收藏。

通過 [**哼哼貓**](https://hhmao.cn/app)，你可以將完整的 YouTube 播放列表批量下載到電腦，支持多種格式和分辨率（包括高清）。操作步驟如下：

1. **安裝桌面客戶端**

   下載並安裝 [**哼哼貓**](https://hhmao.cn/app)，支持 Windows 和 macOS。

2. **複製播放列表鏈接**

   在瀏覽器中打開 YouTube 播放列表，從地址欄複製其 URL。

3. **粘貼鏈接並點擊下載**

   粘貼鏈接後可以預覽媒體資源。

4. **加載更多並篩選內容**

   點擊 **加載更多** 獲取更多視頻。你可以按播放量或點贊數排序，也可以使用篩選器選擇需要的類型。

5. **選擇需要下載的項目**

   全選或勾選需要的項目，然後點擊 **下載所選**。

6. **完成！**

   下載完成後，點擊文件夾圖標即可查看已下載的文件。
