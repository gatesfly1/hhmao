# 提取不成功時，常見原因有哪些？

按出現頻率大致是：

1. 內容已被作者刪除或轉為私密
2. 鏈接是搜索頁/首頁而不是具體某條內容
3. 該條目所在平臺暫未支持
4. 內容有地區限制

換一條同平臺的公開鏈接試一次，就能區分是鏈接的問題還是平臺的問題。
