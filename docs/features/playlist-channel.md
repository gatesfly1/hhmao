# 播放列表 / 频道下载

支持 YouTube、Instagram、Twitter、TikTok、Bilibili 等平台作者主页、频道、播放列表和 Hashtag 列表批量解析下载，自动获取全部作品。

## 主页批量提取

输入作者主页 URL，选择翻页数量或全量，系统会按发布顺序取回该作者公开的全部内容。

## 播放列表

YouTube Playlist、Bilibili 收藏夹等结构化列表会被识别为播放列表，下载时按原顺序保留。

## Hashtag

TikTok、Instagram、Twitter 上的 #标签 页面也能批量解析。注意平台对 hashtag 内容的展示本身有限，热门页 ≠ 全部。
