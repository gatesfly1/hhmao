# How to record Kick live streams?

This guide explains how to use the Meowload desktop app to record Kick live streams and download already-published Kick videos.

## Capabilities

The Meowload desktop app supports two ways to grab Kick content:

1. **Live recording** — record Kick live streams in real time
2. **Video download** — download already-published Kick videos

Both use the **Link download** feature with identical steps.

## Step 1: Copy a Kick link

### Record a live stream

Open the Kick stream page and copy the URL from the address bar:

`https://kick.com/[username]`

Example: `https://kick.com/jupi`

:::tip
- Click "Copy link" to grab the stream URL quickly
- Or just copy the URL from the address bar
:::

### Download an already-published video

Open the Kick video page and copy its URL:

`https://kick.com/[username]/videos/[video_id]`

Example: `https://kick.com/jeff-jian-57/videos/4ef3e6bc-d963-4a04-8b3a-dd0cc0c66f89`

The steps are the same as for live recording.

## Step 2: Paste and start

Open Meowload and head to **Link download**:

1. **Paste the link** — paste the copied Kick URL into the box
2. **Extract** — click **Extract** to let the app parse it
3. **Start recording/downloading** — click **Start recording** to begin

The app automatically shows:

- Stream info (for recording) or video info (for download)
- Extracted results: video, audio stream, cover image
- Live download progress

## Usage notes

| Item | Description |
|---|---|
| **Live recording** | Records in real time; stop any time you want |
| **Video download** | Downloads published videos, usually faster |
| **Save location** | Saved to the download folder configured in the app |
| **File format** | Automatically picks the highest-quality video and audio |
| **Network** | Needs a stable connection; wired network recommended |

## FAQ

**Q: Can I record multiple streams at once?**

A: Yes — Meowload supports batching. Add multiple links to the queue and they run one after another.

**Q: Is there a time limit for recording?**

A: No. Record as long as you want until the broadcast ends or you stop manually.

**Q: Where are the downloaded files?**

A: All files go to the Meowload download folder. You can view or change the location in app settings.
