# 全網視頻 / 圖集提取

## 支持從 1000+ 網站下載視頻、圖片和音樂

hhmao 是一個在線視頻 / 圖集 / 音頻提取工具，覆蓋 YouTube、Bilibili、Twitter、TikTok、Instagram 等 1000+ 站點。

無需安裝，粘貼鏈接即可使用。

## 三步開始

1. 找到要下載的資源，然後從分享選項中複製帖子鏈接
2. 將鏈接粘貼至上方輸入框，點擊「單個鏈接提取」按鈕
3. 選擇視頻清晰度和音頻語言，靈活下載所需格式的資源

## 產品介紹

**哼哼貓** 是一款功能強大的多媒體下載工具，支持視頻下載、直播錄製、文案提取、格式轉換等多種功能。無論是保存喜歡的視頻內容，還是錄製精彩的直播時刻，哼哼貓都能輕鬆幫你實現。

### 核心特性

- 🎬 **視頻 / 音頻 / 圖片下載** —— 支持 1000+ 網站的音視頻圖片資源下載
- 📡 **直播錄製** —— 實時錄製 Twitch、TikTok、Kick 等平臺直播流
- 🎵 **批量格式轉換** —— 支持視頻、圖片、音頻上百種格式的互相轉換
- 🔗 **瀏覽器插件** —— 智能識別任何網頁媒體資源
- ⚡ **批量處理** —— 支持多任務同時下載 / 錄製
