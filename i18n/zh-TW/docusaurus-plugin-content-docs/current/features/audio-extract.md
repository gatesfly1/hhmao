# 視頻提取音頻

支持在線或本地視頻一鍵提取音軌，快速轉為 MP3 或其他音頻格式。

## 在線提取

進入平臺頁面，使用「單個鏈接提取」時勾選「僅保留音頻」。

## 本地提取

客戶端支持選擇本地視頻文件直接轉碼為 MP3 / M4A / WAV。

## 用途

- 剪輯素材庫複用
- 離線播放
- 播客 / 講座二次分發
