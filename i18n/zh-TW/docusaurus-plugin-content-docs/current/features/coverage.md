# 全網覆蓋，1000+ 網站

支持 YouTube、X、Facebook、TikTok、VKontakte、Instagram、rednote 等主流及小眾平臺，涵蓋視頻、音頻、圖集等類型。

## 主流平臺

YouTube、X / Twitter、Facebook、Instagram、TikTok、Twitch、Reddit、Pinterest、Bilibili、微博、小紅書等。

## 小眾平臺

VKontakte、Threads、Sora、afreecatv、Dailymotion、Likee、Tumblr、Snapchat、LinkedIn、SoundCloud 等。

## 持續新增

每週更新支持矩陣，新平臺接入完成後會在「更新日誌」中說明。
