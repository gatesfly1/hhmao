# 批量下載的文件如何保持順序？

批量下載文件時，保持文件順序對於後續整理和查看非常重要。哼哼貓提供了兩種方式來保持文件下載順序。

## 方式 1：默認支持按文件最後修改時間排序

不需要做任何設置，批量下載的文件會自動按文件在提取結果表格裡的展示順序設置修改時間。在文件夾中按「最後修改時間」由近到遠排序，文件順序就和提取結果表格中的順序一致（默認按帖子發佈時間由近到遠）。

## 方式 2：在文件名前添加序號

如果在軟件設置中勾選了「在文件名前添加序號」，下載的文件名前面會自動添加序號（序號對應資源在提取結果表格中的位置）。文件下載完成後，可以直接按文件名排序。

### 常見問題：為什麼「僅下載視頻」時序號不連續？

**原因：** 文件名前的序號對應的是資源在提取結果表格中的位置。點擊「僅下載視頻」時，表格中仍然包含其他類型的資源（音頻、圖片、字幕等），所以視頻的序號會出現跳號。

**解決方法：**

1. 在提取結果表格中，使用「類型篩選」功能
2. 選擇僅展示視頻
3. 篩選後，視頻在表格中的序號會變成連續的
4. 點擊「全部下載」，下載的視頻文件序號就是連續的了
