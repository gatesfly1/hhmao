# 批量修改 MD5

給已下載的視頻/圖集文件重寫哈希值，避免被平臺識別為重複上傳。

## 適用場景

- 多賬號矩陣分發同一素材
- 內容備份後再次上傳時繞過風控
- 自動化內容生產流水線

## 操作步驟

1. 選擇本地一個文件夾作為輸入
2. 選擇輸出文件夾（可與輸入相同，會自動重命名）
3. 點擊「開始修改」

原始視頻 / 圖集不會被改動到不可用，只是文件級別的字節內容被重寫。
