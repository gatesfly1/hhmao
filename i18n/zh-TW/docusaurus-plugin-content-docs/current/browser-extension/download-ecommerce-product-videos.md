# 如何下載電商平臺的產品視頻

在京東、淘寶、拼多多、亞馬遜等電商平臺上看到不錯的商品視頻，想保存下來做素材，卻發現右鍵沒有「另存為」的選項？用手機錄屏畫質模糊、雜音多，效果很差。

使用哼哼貓瀏覽器插件，可以直接獲取高清原視頻，告別模糊錄屏。

這是一個**通用方法**，不僅適用於電商產品視頻，**任何網頁中包含的視頻、音頻、直播**都可以用同樣的方式下載。

## 安裝哼哼貓瀏覽器插件

在瀏覽器應用商店安裝哼哼貓插件：

- **Chrome 瀏覽器**：[Chrome 應用商店安裝](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / 夸克瀏覽器**：[Edge 應用商店安裝](https://microsoftedge.microsoft.com/addons/detail/meowload-videoliveaud/mfmeocjfdcmipdcebfdgpncpmcddmech)

詳細安裝步驟請參考 [安裝哼哼貓瀏覽器插件](install-meowload-extension.md)。

## 下載產品視頻

下面以京東為例演示，其他電商平臺操作方法完全一樣。

**第一步**：在瀏覽器中打開商品頁面，插件會自動識別頁面中的視頻資源。

**第二步**：點擊瀏覽器右上角的哼哼貓圖標，在彈出面板中可以看到識別到的視頻列表。

**第三步**：勾選需要的視頻，點擊 **批量下載** 按鈕。

**第四步**：下載完成後，點擊文件夾圖標即可查看保存的視頻。

## 適用平臺

該方法適用於所有主流電商平臺，包括但不限於：

- **國內**：京東、淘寶、天貓、拼多多、1688、抖音商城
- **海外**：亞馬遜（Amazon）、速賣通（AliExpress）、eBay、Shopee

同樣也適用於其他任何包含視頻的網頁，如新聞網站、社交媒體、在線課程等。
