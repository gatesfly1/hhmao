# Download YouTube videos with the Meowload browser extension

## Why?

Some users run into **403 errors** when downloading YouTube via the desktop app. This is usually caused by network restrictions or YouTube's anti-scraping mechanism.

The Meowload browser extension bypasses those limits and gives a more stable download experience. It also supports **age-restricted** and **region-restricted** videos.

## Steps

### 1️⃣ Install the extension

If you haven't already, see the [install guide](../browser-extension/install-meowload-extension.md).

### 2️⃣ Open the YouTube video

Open the YouTube video in your browser as usual.

### 3️⃣ Click the download button

Once the page loads, the Meowload extension shows a **download button** on the page. Click it → pick a quality and format → confirm.

### 4️⃣ Wait for the download

The extension saves the video to the folder you configured inside the extension.

## FAQ

### ❓ The downloaded video won't play

**Cause**: the player may lack a required codec.

**Fix**:

- Make sure you chose MP4 (most compatible)
- Install a complete codec pack on your system
- Try another player

### ❓ I can't find the download button

**Cause**: the extension may not have loaded properly, or the page needs a refresh.

**Fix**:

- Refresh the page (F5 or Ctrl+R)
- Make sure the extension is enabled in your browser's extension manager
- Restart the browser
- Update the extension to the latest version
