# 多鏈接批量提取

一次粘貼最多 20 條帖子鏈接，系統自動按順序解析並排隊下載圖集與視頻。

## 使用方法

1. 打開主頁的「多鏈接批量提取」入口
2. 每行一條鏈接，粘貼到文本框
3. 點擊「開始批量解析」
4. 解析完成後勾選需要的條目下載

## 適用場景

- 同一作者的多條作品打包下載
- 跨平臺的同主題素材收集
- 備份喜歡的內容以防被刪

## 注意事項

- 每批最多 20 條
- 單條失敗不影響其他條目
- 部分平臺對短時間內的批量請求會限流，失敗時稍等再試
