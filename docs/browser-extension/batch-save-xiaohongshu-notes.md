# 如何批量保存小红书作者主页的视频、图片和文案？

刷小红书时看到绝美壁纸想保存，却发现右下角有水印？遇到喜欢的博主想把 TA 主页的视频存下来慢慢看，却只能一个个手动保存，甚至还在用录屏？

今天教大家一个高效的方法：使用 [哼哼猫](https://hhmao.cn/universal-media-downloader) 浏览器插件，不仅能保存高清无水印的原图，还能一键批量下载博主主页的所有视频、图片和文案，彻底解放双手！

## 前提条件

在电脑浏览器（Chrome / Edge）上打开小红书网页版，使用哼哼猫插件即可一键下载。如果浏览器尚未安装哼哼猫插件，请先参考 [安装教程](install-meowload-extension.md) 完成安装。

## 操作步骤

### 第一步：打开博主主页

在小红书网页版中，进入你想保存内容的博主主页。

### 第二步：等待插件自动识别

打开哼哼猫插件面板，插件会自动识别当前页面中加载的所有视频和图文笔记。

### 第三步：滚动页面加载更多内容

如果需要保存博主的全部笔记，请将页面**持续向下滚动**直到底部。滚动过程中，你会看到插件面板中识别到的资源数量不断增加。滚动到底部后，插件就能识别到博主的所有笔记内容。

### 第四步：全选并批量下载

在插件面板中点击**全选**，然后点击**批量下载**即可。所有视频和图片均为无水印高清原始文件。

## 不只是作者主页

除了博主个人主页之外，在小红书的**首页推荐**和**搜索结果页面**中，同样可以使用哼哼猫插件批量保存页面上显示的所有笔记内容（视频、图片和文案）。
