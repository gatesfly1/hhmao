## 使用步驟

1. **複製 YouTube 鏈接**
   打開你想保存的視頻、播放列表或頻道，點擊「分享」按鈕 → 複製鏈接；短鏈（youtu.be）會自動展開，整段分享文案粘進來也會自動挑出其中的網址。

2. **粘貼到 hhmao**
   回到本頁或打開在線使用頁，把鏈接粘到頂部輸入框，點擊「開始解析」，系統自動解析資源。

3. **選擇清晰度下載**
   列出全部可用的分辨率與音軌（含 8K / 4K / 1080P 視源站提供），挑選需要的畫質直接保存；如需 MP3，可一鍵僅提取音頻。

## 常見問題

### 下載的 YouTube 視頻會帶水印嗎？

不會。hhmao 拿到的是源站原始文件，原始畫質、原始音軌，沒有任何疊加水印。

### YouTube 私密賬號的內容能下載嗎？

不能。需要登錄或訂閱才能看到的內容，我們同樣無法訪問，鏈接會返回失敗。

### YouTube 直鏈有有效期嗎？

源站提供的直鏈通常幾十分鐘到幾小時會失效，重新解析一次即可，不會重複扣費。

### 支持哪些清晰度？

默認列出原始畫質（含 8K / 4K / 1080P 視源站提供），可以自由切換分辨率與音視頻格式。

### 視頻裡的背景音樂會一起保留嗎？

會。保存的是帶完整音軌的 MP4。如果只想要聲音，可使用 YouTube 轉 MP3 工具單獨提取音頻。

### 整個頻道可以一次下載嗎？

能。粘貼頻道主頁地址後，會列出全部視頻，可勾選需要的視頻批量下載。

### 需要安裝軟件嗎？

網頁端不用裝任何軟件，登錄本站賬號後粘貼公開作品的鏈接即可。要成批下載、斷點續傳等高級功能，再考慮裝客戶端。
