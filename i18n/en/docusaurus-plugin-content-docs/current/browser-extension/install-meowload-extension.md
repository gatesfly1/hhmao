# Install the Meowload browser extension

The Meowload browser extension works in Chrome, Edge, Quark, QQ Browser, 360 Browser, Opera, Yandex, and other major browsers. We recommend Chrome or Edge. Two install methods are available.

## From the official store (recommended)

The easiest way — install directly from the official store:

- **Chrome**: [Chrome Web Store](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / Quark**: [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/mfmeocjfdcmipdcebfdgpncpmcddmech)

**Step 1**: On the store page, click **Add to browser**.

**Step 2**: Once installed, click the extension icon in the browser toolbar and pin Meowload to the toolbar.

Whenever you visit a page with a playable video, audio or live stream, the Meowload icon lights up. Click the icon to view detected resources and save what you need.

## Manual install

If your browser can't reach the app store, use the [**manual install**](https://hhmao.cn/manual-install-extension).
