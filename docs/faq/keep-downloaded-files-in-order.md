# 批量下载的文件如何保持顺序？

批量下载文件时，保持文件顺序对于后续整理和查看非常重要。哼哼猫提供了两种方式来保持文件下载顺序。

## 方式 1：默认支持按文件最后修改时间排序

不需要做任何设置，批量下载的文件会自动按文件在提取结果表格里的展示顺序设置修改时间。在文件夹中按「最后修改时间」由近到远排序，文件顺序就和提取结果表格中的顺序一致（默认按帖子发布时间由近到远）。

## 方式 2：在文件名前添加序号

如果在软件设置中勾选了「在文件名前添加序号」，下载的文件名前面会自动添加序号（序号对应资源在提取结果表格中的位置）。文件下载完成后，可以直接按文件名排序。

### 常见问题：为什么「仅下载视频」时序号不连续？

**原因：** 文件名前的序号对应的是资源在提取结果表格中的位置。点击「仅下载视频」时，表格中仍然包含其他类型的资源（音频、图片、字幕等），所以视频的序号会出现跳号。

**解决方法：**

1. 在提取结果表格中，使用「类型筛选」功能
2. 选择仅展示视频
3. 筛选后，视频在表格中的序号会变成连续的
4. 点击「全部下载」，下载的视频文件序号就是连续的了
