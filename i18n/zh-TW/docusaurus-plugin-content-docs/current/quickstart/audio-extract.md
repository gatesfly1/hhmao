# 視頻轉音頻

支持在線視頻一鍵提取音軌，或對本地視頻做轉碼，輸出 MP3 / M4A / WAV 等格式。

## 在線提取

進入任意平臺頁面，使用「單個鏈接提取」時勾選「僅保留音頻」，即可在不下載完整視頻的情況下獲得音頻文件。

## 本地轉碼

1. 打開客戶端的「視頻轉音頻」面板
2. 選擇本地視頻文件（mp4 / mov / mkv / webm）
3. 選擇目標格式和碼率
4. 輸出到指定目錄

## 適用場景

- 抽取講座 / 播客的背景音軌
- 把 MV 轉成 MP3 離線聽
- 準備剪輯素材庫
