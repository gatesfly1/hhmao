# 下载 YouTube 视频时遇到网络问题怎么解决？

使用 [哼哼猫](https://hhmao.cn/app) 电脑版下载 YouTube、Instagram、Twitter 等平台的资源时，如果遇到以下错误提示：

- **请求超时**
- **网络连接异常**
- **连接超时**

通常是因为电脑的网络环境无法直接访问这些网站。请按照以下步骤排查和解决。

## 第一步：使用网络测试功能

在下载页面中，点击提示信息旁的 **「网络测试」** 链接，软件会自动打开「设置 - 网络」页面，并检测当前网络环境到各主要网站的连通性。

## 第二步：查看测试结果

在设置页面的 **「网络」** 选项卡中，点击 **「开始测试」** 按钮，软件会逐一测试到 YouTube、Twitter、Instagram、Baidu 等网站的连通性。

- ✅ 表示可以正常连接
- ❌ 表示无法连接

如果 YouTube、Twitter 等网站显示 ❌，说明当前网络环境无法访问这些网站，可能需要配置代理。

## 第三步：配置代理

哼哼猫默认使用 **「系统代理」** 模式，即跟随操作系统的代理设置。请确认：

1. **电脑上已安装并开启了代理工具**
2. **代理工具已开启「系统代理」模式**，使系统全局流量通过代理
3. 配置完成后，回到哼哼猫的网络测试页面，重新点击 **「开始测试」**，确认网站连通性测试全部通过 ✅

:::tip
如果代理工具已开启但测试仍然失败，请检查代理工具是否正常工作（可以尝试在浏览器中打开 YouTube 来验证），或者尝试切换代理节点。
:::

## 配置了代理但还是下载失败？

- 检查代理工具是否开启了 **「系统代理」** 模式（而非仅规则模式）
- 尝试切换代理节点后重新测试
- 确认代理工具本身可以正常访问 YouTube（用浏览器验证）
