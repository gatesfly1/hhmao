# 單個鏈接提取

粘貼一條帖子鏈接，系統自動解析後可下載原始畫質視頻、圖集或音頻。

## 步驟

1. 在目標 App/網頁打開你想保存的帖子，使用「分享」→ 複製鏈接
2. 回到 hhmao 主頁，把鏈接粘到頂部輸入框
3. 點擊「單個鏈接提取」按鈕
4. 解析完成後挑選畫質或 MP3，保存到本地

## 支持的鏈接形式

- 移動端分享鏈接（含 utm_source / share_token 等參數也能識別）
- 桌面端 URL
- 短鏈（t.co / youtu.be / b23.tv 等）

## 適用平臺

幾乎所有 hhmao.cn 列出的平臺都支持單個鏈接提取。
