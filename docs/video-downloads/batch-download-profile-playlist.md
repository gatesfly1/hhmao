# 如何批量下载主页、播放列表、频道和 Hashtag 页面的视频、音频和图片？

遇到喜欢的创作者，想把 TA 主页的作品都下载下来慢慢看，却要一个个手动保存？

[哼哼猫](https://hhmao.cn/app) 电脑版提供了**主页 / 播放列表批量下载**功能，只需粘贴创作者的主页链接，就能自动提取页面内可获取的视频、音频和图片，一键批量下载到本地。该功能已支持 1000+ 网站，包括但不限于：

- **YouTube**：频道页、播放列表、Shorts 页面
- **Instagram**：用户主页、Hashtag 页面
- **TikTok**：用户主页、Hashtag 页面
- **B 站**：用户主页、合集页面
- **SoundCloud**：作者主页、播放列表、专辑中的公开音频
- 以及 Twitter(X)、Twitch、微博、AcFun 等更多平台

## 操作步骤

### 第一步：复制目标页面链接

打开你想批量下载的创作者主页、播放列表、频道页或话题标签页，从浏览器地址栏复制页面链接。

### 第二步：粘贴链接并提取

打开哼哼猫电脑软件，在左侧菜单选择**主页批量下载**，将复制的链接粘贴到输入框中，点击**提取**按钮。

软件会按作品发布时间从近到远分页提取内容。你可以点击**加载下一页**逐页加载，也可以选择**一次加载 5 页**或**一次加载全部**来获取列表中的所有作品。

### 第三步：排序、筛选并批量下载

提取完成后，你可以对结果进行调整：

- **排序**：默认按发布时间由近到远排列，也支持按浏览量或点赞数排序
- **筛选**：按文件类型筛选，包括视频、音频、图片和字幕

确认后点击**全部下载**即可一键批量保存到本地。也可以通过**仅下载视频**等快捷按钮，只下载某一类型的文件。
