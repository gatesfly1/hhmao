# 萬能音視頻嗅探

內置瀏覽器支持任意網頁資源嗅探，自動識別音樂與視頻鏈接，支持一鍵批量下載，真正實現能播就能下。

## 工作原理

打開內置瀏覽器訪問任意網頁，嗅探模塊會監聽網絡請求並按文件類型 / 字節範圍識別音視頻流，列出可下載的資源。

## 典型用法

- 打開網頁版視頻站點 → 嗅探 → 批量下載
- 瀏覽論壇帖子時直接抓取內嵌的 mp4 / m3u8
- 在線播放的同時後臺緩存
