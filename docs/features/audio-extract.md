# 视频提取音频

支持在线或本地视频一键提取音轨，快速转为 MP3 或其他音频格式。

## 在线提取

进入平台页面，使用「单个链接提取」时勾选「仅保留音频」。

## 本地提取

客户端支持选择本地视频文件直接转码为 MP3 / M4A / WAV。

## 用途

- 剪辑素材库复用
- 离线播放
- 播客 / 讲座二次分发
