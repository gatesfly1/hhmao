# 如何下载电商平台的产品视频

在京东、淘宝、拼多多、亚马逊等电商平台上看到不错的商品视频，想保存下来做素材，却发现右键没有「另存为」的选项？用手机录屏画质模糊、杂音多，效果很差。

使用哼哼猫浏览器插件，可以直接获取高清原视频，告别模糊录屏。

这是一个**通用方法**，不仅适用于电商产品视频，**任何网页中包含的视频、音频、直播**都可以用同样的方式下载。

## 安装哼哼猫浏览器插件

在浏览器应用商店安装哼哼猫插件：

- **Chrome 浏览器**：[Chrome 应用商店安装](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / 夸克浏览器**：[Edge 应用商店安装](https://microsoftedge.microsoft.com/addons/detail/meowload-videoliveaud/mfmeocjfdcmipdcebfdgpncpmcddmech)

详细安装步骤请参考 [安装哼哼猫浏览器插件](install-meowload-extension.md)。

## 下载产品视频

下面以京东为例演示，其他电商平台操作方法完全一样。

**第一步**：在浏览器中打开商品页面，插件会自动识别页面中的视频资源。

**第二步**：点击浏览器右上角的哼哼猫图标，在弹出面板中可以看到识别到的视频列表。

**第三步**：勾选需要的视频，点击 **批量下载** 按钮。

**第四步**：下载完成后，点击文件夹图标即可查看保存的视频。

## 适用平台

该方法适用于所有主流电商平台，包括但不限于：

- **国内**：京东、淘宝、天猫、拼多多、1688、抖音商城
- **海外**：亚马逊（Amazon）、速卖通（AliExpress）、eBay、Shopee

同样也适用于其他任何包含视频的网页，如新闻网站、社交媒体、在线课程等。
