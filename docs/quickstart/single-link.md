# 单个链接提取

粘贴一条帖子链接，系统自动解析后可下载原始画质视频、图集或音频。

## 步骤

1. 在目标 App/网页打开你想保存的帖子，使用「分享」→ 复制链接
2. 回到 hhmao 主页，把链接粘到顶部输入框
3. 点击「单个链接提取」按钮
4. 解析完成后挑选画质或 MP3，保存到本地

## 支持的链接形式

- 移动端分享链接（含 utm_source / share_token 等参数也能识别）
- 桌面端 URL
- 短链（t.co / youtu.be / b23.tv 等）

## 适用平台

几乎所有 hhmao.cn 列出的平台都支持单个链接提取。
