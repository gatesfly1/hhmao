# 安装哼哼猫浏览器插件

哼哼猫浏览器插件支持 Chrome、Edge、夸克、QQ 浏览器、360 浏览器、Opera、Yandex 等主流浏览器，推荐在 Chrome 或 Edge 中使用。以下介绍两种安装方式。

## 从应用商店安装（推荐）

这是最简单也是最推荐的安装方式，直接从官方商店安装：

- **Chrome 浏览器**：[Chrome 应用商店](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / 夸克浏览器**：[Edge 应用商店](https://microsoftedge.microsoft.com/addons/detail/mfmeocjfdcmipdcebfdgpncpmcddmech)

**第一步**：在应用商店页面点击 **添加扩展程序** 按钮。

**第二步**：安装完成后，点击浏览器右上角的插件图标，将哼哼猫 **固定至工具栏**。

当你访问任何网页时，如果页面中包含可播放的视频、音频或直播，哼哼猫图标会自动点亮。点击图标即可查看嗅探到的资源，选择需要的内容下载保存到本地。

## 手动安装

如果你使用的浏览器无法访问应用商店，可以通过 [**手动安装方式**](https://hhmao.cn/manual-install-extension) 完成安装。
