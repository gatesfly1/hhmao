# 多链接批量提取

支持粘贴最多 20 条帖子链接，系统自动提取资源，批量下载图集与视频。

## 与「主页批量」的区别

- 多链接：每条都是不同作者、不同内容的独立帖子
- 主页批量：给定一个作者主页，按页把他公开发布的内容取回来

## 排错

失败的条目会标注原因，可单独重试。其他成功条目不受影响。
