# YouTube 字幕下載 - 支持多語言、多種字幕格式

觀看 YouTube 視頻時，字幕對於語言學習、內容理解和二次創作都非常重要。哼哼貓提供了**兩種便捷的方式**下載 YouTube 字幕，支持多種語言和格式，滿足不同場景的需求。

## 方式一：桌面軟件下載字幕（推薦 SRT 格式）

### 操作步驟

1. **複製視頻鏈接**：在 YouTube 上找到想要下載字幕的視頻，複製視頻分享鏈接（例如：`https://youtu.be/Ah_uuTwGOYU`）
2. **打開哼哼貓軟件**：啟動哼哼貓桌面軟件，在左側菜單選擇「**鏈接下載**」功能
3. **粘貼鏈接並提取**：將複製的 YouTube 鏈接粘貼到輸入框中，點擊綠色的「**提取**」按鈕
4. **選擇字幕語言下載**：如果視頻包含字幕，提取結果列表中會顯示字幕下載選項。點擊字幕行右側的語言下拉菜單，選擇你需要的語言（如中文簡體、英文等），然後點擊下載按鈕即可

### 方式一特點

- **操作簡單**：與下載視頻、音頻、圖片流程一致，可以同時下載視頻、音頻、圖片和字幕
- **默認 SRT 格式**：下載的字幕為通用的 SRT 格式，兼容性最好
- **格式限制**：僅支持 SRT 格式，如需其他格式請使用方式二

## 方式二：網頁端下載字幕（支持多種格式）

### 操作步驟

1. **訪問網頁工具**：打開哼哼貓網頁端的 [**YouTube 視頻字幕下載功能**](https://hhmao.cn/youtube-subtitle-downloader)
2. **粘貼鏈接並提取**：將 YouTube 視頻分享鏈接粘貼到輸入框中，點擊「**單個鏈接提取**」按鈕
3. **選擇語言和格式**：提取成功後，頁面會顯示該視頻的所有可用語言字幕。每個語言右側都有：格式下拉菜單，點擊語言標籤右側的下拉按鈕，可以選擇字幕格式
4. **下載字幕**：選擇好語言和格式後，點擊下載按鈕即可保存到本地

### 支持的字幕格式

| 格式 | 說明 | 適用場景 |
|---|---|---|
| **SRT** | 最通用的字幕格式 | 視頻編輯軟件、播放器、字幕翻譯工具 |
| **VTT** | Web 視頻字幕標準格式 | 網頁播放器、HTML5 視頻 |
| **TTML** | 時序文本標記語言 | 專業視頻製作、廣播電視 |
| **JSON3** | JSON 格式的字幕數據 | 開發者、數據分析、程序處理 |
| **SRV1/SRV2/SRV3** | YouTube 原始字幕格式 | 特殊需求、格式研究 |

### 方式二特點

- **格式豐富**：支持 SRT / VTT / TTML / JSON3 / SRV1 / SRV2 / SRV3 等多種格式
- **無需安裝**：網頁端使用，任何設備都可訪問

## 常見問題

**Q：如果視頻沒有字幕怎麼辦？**

A：部分視頻可能沒有上傳字幕，這種情況下提取結果中不會顯示字幕選項。您可以嘗試查看視頻是否有自動生成的字幕（auto-generated）。

**Q：下載的字幕是中英雙語的嗎？**

A：下載的是單一語言字幕。如需雙語字幕，可以分別下載兩種語言，然後使用字幕編輯工具合併。

**Q：字幕文件如何使用？**

A：下載的 SRT 字幕可以在視頻播放器（如 VLC、PotPlayer）中加載，也可以導入視頻編輯軟件（如 PR、剪映）使用。
