# How to batch-save videos, images and captions from a Xiaohongshu author profile?

Spotted gorgeous wallpaper on Xiaohongshu but the bottom-right watermark spoils it? Love a creator's videos but stuck saving them one by one — or worse, screen-recording?

Here's a better way: use the [Meowload](https://hhmao.cn/universal-media-downloader) browser extension. Save HD watermark-free originals in one go and batch download everything on a creator's profile — videos, images and captions.

## Prerequisites

Use the Meowload extension in Chrome / Edge on the desktop web version of Xiaohongshu. If you haven't installed it yet, see the [install guide](install-meowload-extension.md).

## Steps

### Step 1: Open the creator's profile

Go to the creator's profile on Xiaohongshu web.

### Step 2: Wait for the extension to detect content

Open the Meowload panel. The extension automatically detects every video and image-post on the current page.

### Step 3: Scroll to load more

To save the creator's full archive, **scroll down** continuously to the bottom. As you scroll, the resource count in the panel grows. When you hit the bottom, every note is in the list.

### Step 4: Select all and download

Click **Select all** in the panel, then **Batch download**. All videos and images are saved as HD originals without watermarks.

## Not just author profiles

In addition to creator profiles, you can use the Meowload extension on Xiaohongshu's **homepage recommendations** and **search results** to batch-save every note (videos, images and captions) shown on the page.
