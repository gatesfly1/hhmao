# 如何下载 YouTube 播放列表

YouTube 上有数百万个播放列表，涵盖音乐专辑、教学系列、精选合集等各类主题。将整个播放列表保存到本地，方便离线观看、学习或个人收藏。

通过 [**哼哼猫**](https://hhmao.cn/app)，你可以将完整的 YouTube 播放列表批量下载到电脑，支持多种格式和分辨率（包括高清）。操作步骤如下：

1. **安装桌面客户端**

   下载并安装 [**哼哼猫**](https://hhmao.cn/app)，支持 Windows 和 macOS。

2. **复制播放列表链接**

   在浏览器中打开 YouTube 播放列表，从地址栏复制其 URL。

3. **粘贴链接并点击下载**

   粘贴链接后可以预览媒体资源。

4. **加载更多并筛选内容**

   点击 **加载更多** 获取更多视频。你可以按播放量或点赞数排序，也可以使用筛选器选择需要的类型。

5. **选择需要下载的项目**

   全选或勾选需要的项目，然后点击 **下载所选**。

6. **完成！**

   下载完成后，点击文件夹图标即可查看已下载的文件。
