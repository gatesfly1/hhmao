# 视频转音频

支持在线视频一键提取音轨，或对本地视频做转码，输出 MP3 / M4A / WAV 等格式。

## 在线提取

进入任意平台页面，使用「单个链接提取」时勾选「仅保留音频」，即可在不下载完整视频的情况下获得音频文件。

## 本地转码

1. 打开客户端的「视频转音频」面板
2. 选择本地视频文件（mp4 / mov / mkv / webm）
3. 选择目标格式和码率
4. 输出到指定目录

## 适用场景

- 抽取讲座 / 播客的背景音轨
- 把 MV 转成 MP3 离线听
- 准备剪辑素材库
