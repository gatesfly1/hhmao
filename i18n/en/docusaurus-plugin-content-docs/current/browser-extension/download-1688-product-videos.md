# How to download 1688 product videos

Anyone running e-commerce knows the pain: you spot a nice product video on 1688 and want to save it as material, but right-click doesn't show "Save as".

Recording the screen with your phone? Blurry, noisy, with buttons in the way — unusable.

A single browser extension is all it takes to one-click download the original HD video.

## Install the Meowload browser extension

Install from the browser store:

- **Chrome**: [Chrome Web Store](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / Quark**: [Edge Add-ons](https://microsoftedge.microsoft.com/addons/detail/meowload-videoliveaud/mfmeocjfdcmipdcebfdgpncpmcddmech)

See [Install the Meowload browser extension](install-meowload-extension.md) for full steps.

## Download a product video

After installing the extension, open a 1688 product page. The extension auto-detects the videos on the page. Click the Meowload icon to see what was found.

Click **Download**. When it's done, click the folder icon to view your saved video.
