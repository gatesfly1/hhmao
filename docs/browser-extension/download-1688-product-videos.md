# 如何下载 1688 上的商品视频

做电商的朋友肯定遇到过这个问题：在 1688 看到一个不错的商品视频，想保存下来做素材，右键点击却发现没有「另存为」的选项。

用手机对着屏幕录屏？画质模糊、杂音多、还有按钮遮挡，效果很差。

其实只需要一个浏览器插件，就能一键下载高清原视频。

## 安装哼哼猫浏览器插件

在浏览器应用商店安装哼哼猫插件：

- **Chrome 浏览器**：[Chrome 应用商店安装](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / 夸克浏览器**：[Edge 应用商店安装](https://microsoftedge.microsoft.com/addons/detail/meowload-videoliveaud/mfmeocjfdcmipdcebfdgpncpmcddmech)

详细安装步骤请参考 [安装哼哼猫浏览器插件](install-meowload-extension.md)。

## 下载商品视频

安装好插件后，打开 1688 商品页面，插件会自动识别页面中的视频资源。点击哼哼猫图标即可查看嗅探到的视频。

点击 **下载** 按钮，下载完成后点击文件夹图标即可查看保存的视频。
