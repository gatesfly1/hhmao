# 安裝哼哼貓瀏覽器插件

哼哼貓瀏覽器插件支持 Chrome、Edge、夸克、QQ 瀏覽器、360 瀏覽器、Opera、Yandex 等主流瀏覽器，推薦在 Chrome 或 Edge 中使用。以下介紹兩種安裝方式。

## 從應用商店安裝（推薦）

這是最簡單也是最推薦的安裝方式，直接從官方商店安裝：

- **Chrome 瀏覽器**：[Chrome 應用商店](https://chromewebstore.google.com/detail/meowload-videoliveaudioim/gnplpcfnikehohdgnfnfcienljcbaogj)
- **Edge / 夸克瀏覽器**：[Edge 應用商店](https://microsoftedge.microsoft.com/addons/detail/mfmeocjfdcmipdcebfdgpncpmcddmech)

**第一步**：在應用商店頁面點擊 **添加擴展程序** 按鈕。

**第二步**：安裝完成後，點擊瀏覽器右上角的插件圖標，將哼哼貓 **固定至工具欄**。

當你訪問任何網頁時，如果頁面中包含可播放的視頻、音頻或直播，哼哼貓圖標會自動點亮。點擊圖標即可查看嗅探到的資源，選擇需要的內容下載保存到本地。

## 手動安裝

如果你使用的瀏覽器無法訪問應用商店，可以通過 [**手動安裝方式**](https://hhmao.cn/manual-install-extension) 完成安裝。
