# 賬號和會員常見問題

關於哼哼貓賬號和會員相關的常見疑問，本頁面為您一一解答。包括賬號登錄限制、會員版本選擇、密碼錯誤處理等問題。

## 個人版賬號可以在幾臺電腦登錄

個人版賬號**最多可在 2 臺電腦同時登錄**。在網站上直接註冊的賬號為**個人版本賬號**，因此受到同時登錄設備數的限制。此限制主要是為了保護賬號安全和公平使用。

如果您的使用場景超過 2 臺設備（比如團隊 / 企業場景），可以聯繫客服付費**升級為團隊版本賬號**。

### 注意事項

如果檢測到異常的同時登錄行為（如頻繁在多地登錄），系統會出於安全考慮對賬號進行限制。請妥善保管賬號信息。

## 有團隊 / 企業版本會員嗎？

哼哼貓對團隊和企業用戶提供了**專門的團隊版本會員**。請聯繫客服購買團隊版本會員。

## 登錄時提示賬號或密碼錯誤？

**常見原因和解決方案：**

| 問題 | 現象 | 解決方案 |
|---|---|---|
| **大小寫錯誤** | 密碼中有大寫字母，但輸入時全部小寫 | 檢查 Caps Lock 是否開啟，仔細輸入密碼 |
| **郵箱後綴錯誤** | 常見的 `.com` 打成了 `.con` 或其他 | 仔細檢查郵箱後綴，特別注意 `.com`、`.cn` 等 |
| **中英文標點混用** | 密碼中用的是英文標點，但輸入了中文標點 | 關閉中文輸入法，切換到英文輸入法後重新輸入 |
| **全角和半角混用** | 密碼中是半角符號，輸入時變成了全角 | 確保使用英文輸入法（半角狀態）輸入特殊符號 |

### 小貼士

如果密碼中包含特殊符號，建議在輸入前驗證輸入法狀態：

- **英文輸入法**（推薦）：顯示標點為半角
- **中文輸入法全角狀態**：標點會加寬，容易出錯

### 還是無法登錄？

如果按照上述方案檢查後仍無法登錄，可以點擊「**忘記密碼**」進行重置，或聯繫客服尋求幫助。
