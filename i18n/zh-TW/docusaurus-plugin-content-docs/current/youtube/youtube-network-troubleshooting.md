# 下載 YouTube 視頻時遇到網絡問題怎麼解決？

使用 [哼哼貓](https://hhmao.cn/app) 電腦版下載 YouTube、Instagram、Twitter 等平臺的資源時，如果遇到以下錯誤提示：

- **請求超時**
- **網絡連接異常**
- **連接超時**

通常是因為電腦的網絡環境無法直接訪問這些網站。請按照以下步驟排查和解決。

## 第一步：使用網絡測試功能

在下載頁面中，點擊提示信息旁的 **「網絡測試」** 鏈接，軟件會自動打開「設置 - 網絡」頁面，並檢測當前網絡環境到各主要網站的連通性。

## 第二步：查看測試結果

在設置頁面的 **「網絡」** 選項卡中，點擊 **「開始測試」** 按鈕，軟件會逐一測試到 YouTube、Twitter、Instagram、Baidu 等網站的連通性。

- ✅ 表示可以正常連接
- ❌ 表示無法連接

如果 YouTube、Twitter 等網站顯示 ❌，說明當前網絡環境無法訪問這些網站，可能需要配置代理。

## 第三步：配置代理

哼哼貓默認使用 **「系統代理」** 模式，即跟隨操作系統的代理設置。請確認：

1. **電腦上已安裝並開啟了代理工具**
2. **代理工具已開啟「系統代理」模式**，使系統全局流量通過代理
3. 配置完成後，回到哼哼貓的網絡測試頁面，重新點擊 **「開始測試」**，確認網站連通性測試全部通過 ✅

:::tip
如果代理工具已開啟但測試仍然失敗，請檢查代理工具是否正常工作（可以嘗試在瀏覽器中打開 YouTube 來驗證），或者嘗試切換代理節點。
:::

## 配置了代理但還是下載失敗？

- 檢查代理工具是否開啟了 **「系統代理」** 模式（而非僅規則模式）
- 嘗試切換代理節點後重新測試
- 確認代理工具本身可以正常訪問 YouTube（用瀏覽器驗證）
