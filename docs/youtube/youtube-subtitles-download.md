# YouTube 字幕下载 - 支持多语言、多种字幕格式

观看 YouTube 视频时，字幕对于语言学习、内容理解和二次创作都非常重要。哼哼猫提供了**两种便捷的方式**下载 YouTube 字幕，支持多种语言和格式，满足不同场景的需求。

## 方式一：桌面软件下载字幕（推荐 SRT 格式）

### 操作步骤

1. **复制视频链接**：在 YouTube 上找到想要下载字幕的视频，复制视频分享链接（例如：`https://youtu.be/Ah_uuTwGOYU`）
2. **打开哼哼猫软件**：启动哼哼猫桌面软件，在左侧菜单选择「**链接下载**」功能
3. **粘贴链接并提取**：将复制的 YouTube 链接粘贴到输入框中，点击绿色的「**提取**」按钮
4. **选择字幕语言下载**：如果视频包含字幕，提取结果列表中会显示字幕下载选项。点击字幕行右侧的语言下拉菜单，选择你需要的语言（如中文简体、英文等），然后点击下载按钮即可

### 方式一特点

- **操作简单**：与下载视频、音频、图片流程一致，可以同时下载视频、音频、图片和字幕
- **默认 SRT 格式**：下载的字幕为通用的 SRT 格式，兼容性最好
- **格式限制**：仅支持 SRT 格式，如需其他格式请使用方式二

## 方式二：网页端下载字幕（支持多种格式）

### 操作步骤

1. **访问网页工具**：打开哼哼猫网页端的 [**YouTube 视频字幕下载功能**](https://hhmao.cn/youtube-subtitle-downloader)
2. **粘贴链接并提取**：将 YouTube 视频分享链接粘贴到输入框中，点击「**单个链接提取**」按钮
3. **选择语言和格式**：提取成功后，页面会显示该视频的所有可用语言字幕。每个语言右侧都有：格式下拉菜单，点击语言标签右侧的下拉按钮，可以选择字幕格式
4. **下载字幕**：选择好语言和格式后，点击下载按钮即可保存到本地

### 支持的字幕格式

| 格式 | 说明 | 适用场景 |
|---|---|---|
| **SRT** | 最通用的字幕格式 | 视频编辑软件、播放器、字幕翻译工具 |
| **VTT** | Web 视频字幕标准格式 | 网页播放器、HTML5 视频 |
| **TTML** | 时序文本标记语言 | 专业视频制作、广播电视 |
| **JSON3** | JSON 格式的字幕数据 | 开发者、数据分析、程序处理 |
| **SRV1/SRV2/SRV3** | YouTube 原始字幕格式 | 特殊需求、格式研究 |

### 方式二特点

- **格式丰富**：支持 SRT / VTT / TTML / JSON3 / SRV1 / SRV2 / SRV3 等多种格式
- **无需安装**：网页端使用，任何设备都可访问

## 常见问题

**Q：如果视频没有字幕怎么办？**

A：部分视频可能没有上传字幕，这种情况下提取结果中不会显示字幕选项。您可以尝试查看视频是否有自动生成的字幕（auto-generated）。

**Q：下载的字幕是中英双语的吗？**

A：下载的是单一语言字幕。如需双语字幕，可以分别下载两种语言，然后使用字幕编辑工具合并。

**Q：字幕文件如何使用？**

A：下载的 SRT 字幕可以在视频播放器（如 VLC、PotPlayer）中加载，也可以导入视频编辑软件（如 PR、剪映）使用。
