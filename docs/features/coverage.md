# 全网覆盖，1000+ 网站

支持 YouTube、X、Facebook、TikTok、VKontakte、Instagram、rednote 等主流及小众平台，涵盖视频、音频、图集等类型。

## 主流平台

YouTube、X / Twitter、Facebook、Instagram、TikTok、Twitch、Reddit、Pinterest、Bilibili、微博、小红书等。

## 小众平台

VKontakte、Threads、Sora、afreecatv、Dailymotion、Likee、Tumblr、Snapchat、LinkedIn、SoundCloud 等。

## 持续新增

每周更新支持矩阵，新平台接入完成后会在「更新日志」中说明。
