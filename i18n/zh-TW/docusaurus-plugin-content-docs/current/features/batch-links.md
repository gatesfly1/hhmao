# 多鏈接批量提取

支持粘貼最多 20 條帖子鏈接，系統自動提取資源，批量下載圖集與視頻。

## 與「主頁批量」的區別

- 多鏈接：每條都是不同作者、不同內容的獨立帖子
- 主頁批量：給定一個作者主頁，按頁把他公開發布的內容取回來

## 排錯

失敗的條目會標註原因，可單獨重試。其他成功條目不受影響。
