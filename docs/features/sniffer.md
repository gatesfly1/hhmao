# 万能音视频嗅探

内置浏览器支持任意网页资源嗅探，自动识别音乐与视频链接，支持一键批量下载，真正实现能播就能下。

## 工作原理

打开内置浏览器访问任意网页，嗅探模块会监听网络请求并按文件类型 / 字节范围识别音视频流，列出可下载的资源。

## 典型用法

- 打开网页版视频站点 → 嗅探 → 批量下载
- 浏览论坛帖子时直接抓取内嵌的 mp4 / m3u8
- 在线播放的同时后台缓存
