# 如何批量保存小紅書作者主頁的視頻、圖片和文案？

刷小紅書時看到絕美壁紙想保存，卻發現右下角有水印？遇到喜歡的博主想把 TA 主頁的視頻存下來慢慢看，卻只能一個個手動保存，甚至還在用錄屏？

今天教大家一個高效的方法：使用 [哼哼貓](https://hhmao.cn/universal-media-downloader) 瀏覽器插件，不僅能保存高清無水印的原圖，還能一鍵批量下載博主主頁的所有視頻、圖片和文案，徹底解放雙手！

## 前提條件

在電腦瀏覽器（Chrome / Edge）上打開小紅書網頁版，使用哼哼貓插件即可一鍵下載。如果瀏覽器尚未安裝哼哼貓插件，請先參考 [安裝教程](install-meowload-extension.md) 完成安裝。

## 操作步驟

### 第一步：打開博主主頁

在小紅書網頁版中，進入你想保存內容的博主主頁。

### 第二步：等待插件自動識別

打開哼哼貓插件面板，插件會自動識別當前頁面中加載的所有視頻和圖文筆記。

### 第三步：滾動頁面加載更多內容

如果需要保存博主的全部筆記，請將頁面**持續向下滾動**直到底部。滾動過程中，你會看到插件面板中識別到的資源數量不斷增加。滾動到底部後，插件就能識別到博主的所有筆記內容。

### 第四步：全選並批量下載

在插件面板中點擊**全選**，然後點擊**批量下載**即可。所有視頻和圖片均為無水印高清原始文件。

## 不只是作者主頁

除了博主個人主頁之外，在小紅書的**首頁推薦**和**搜索結果頁面**中，同樣可以使用哼哼貓插件批量保存頁面上顯示的所有筆記內容（視頻、圖片和文案）。
